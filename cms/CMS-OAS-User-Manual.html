Ang OAS-CMS

Ang OAS Content Management System o ang OAS-CMS, hatid ng iConcept IT Solutions, ay isang system na idinisenyo upang mapadali ang pag-aayos, pag-publish, at pamamahala ng digital content sa website ng OAS. Sa pamamagitan ng system na ito, hindi na kinakailangan ang malalim na kaalaman sa coding upang makapag-update ng content sa website.

Ano-ano ang Maaaring Gawin sa CMS?

Pag-view, pag-add, pag-edit, at pag-delete ng content sa OAS website.

  • View Content Silipin ang mga kasalukuyang mga post sa website.
  • Add Content Magdagdag ng mga bagong artikulo o updates sa website.
  • Edit Content Baguhin o i-update ang mga naka-post.
  • Delete Content Magtanggal ng mga outdated o maling posts.

4 Paano Gamitin ang CMS?

Pumili sa sidebar ng section na nais ayusin ang content. Halimbawa, ang News and Announcements section.

Larawan 18. Paano Gamitin ang CMS?

Pagkapindot, makikita ang mga post na nilalaman ng section na napili. Maaari rin mag-search ng posts o mag-sort ng posts ayon sa petsa ng pag-post nito.

Larawan 19. Paano Gamitin ang CMS?

4.4 Hero Slider

Upang ma-access ang section na ito sa OAS-CMS, pindutin ang Hero Slider sa sidebar. Upang makapag-add ng content, pindutin ang Add Slide.

Larawan 32. Hero Slider

Mayroong anim na detalyeng dapat punan, ito ay ang label, title, text, button link na \href, button text, at slide image.

Larawan 33. Hero Slider

Ang label isang maikling text na nagsisilbing kategorya o panimula ng slide. Ito ay makikita sa itaas ng pamagat.

Larawan 34. Hero Slider

Ang title, ay ang headline ng slide. Ito ang pinakamalaking teksto at siyang unang napapansin.

Larawan 35. Hero Slider
Larawan 36. Hero Slider

Ang button link na pupuntahan ng gumagamit kapag pinindot ang button. Maaari itong magturo sa ibang pahina ng website tulad ng /home,/about, /government, /services, /transparency, at /news. Ito ay nagsisimula sa isang forward slash (/).

I-hover ang mouse sa menu o bahagi ng website na nais mong ituro ng button. Makikita sa lower-left corner ng browser ang URL o address.

Larawan 37. Hero Slider

Kopyahin lamang ang bahagi ng URL na nagsisimula sa forward slash (/) at iyon ang ilagay sa Button Link (href).

Larawan 38. Hero Slider

Ang Button Text ay ang text na nakalagay sa button. Halimbawa, sa slide na ito, ang button text ay “Learn More”

Larawan 39. Hero Slider

Ang Slide Image ay ang larawang ipapakita sa slider. Siguraduhing tama at malinaw ito.

Larawan 40. Hero Slider

Pindutin ang Save button pagkatapos punan lahat ng detalyeng kinakailangan.

Larawan 41. Hero Slider

Pindutin ang Edit button kung kailangang baguhin ang laman ng slide. Pindutin ang Delete button kung kailangang burahin ang slide.
