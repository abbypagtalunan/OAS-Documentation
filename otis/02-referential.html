Section 2

Referential

The Referential menu holds the reference lists that the rest of TIS depends on: funds, allotments, the chart of accounts, accountable forms, officers, cost centers, official receipt templates and similar tables. This section explains each page, each window and each dropdown list.

Who can use this section. The Referential menu appears for an account whose role is Admin. These lists feed the other menus, so a change here changes what cashiers, issuers and other users see. Add, edit and delete only when you are sure.

2.1 How the Referential pages work

Open the sidebar with the menu icon (three lines) at the top left and click Referential. It opens seven choices: Fund, Allotment, FPP, Chart Of Accounts, Accountability, Collection Type and Cemetery. Fund, Allotment, FPP, Chart Of Accounts and Accountability open into smaller lists. Collection Type and Cemetery open their page directly.

Figure 2.1. The sidebar with Referential open. 1 Referential · 2 The seven choices. The name and email are blurred.

Accountability has twelve pages: Accountable Forms, Check Booklets, Bank Depository, Form Code, Officer Type, LiqDisb Collector, Cost Center, Creditor/Payee, OR Template, Accountant, Treasurer and Mayor. Scroll the sidebar to see all of them.

Figure 2.2. The sidebar scrolled to the Accountability pages. 1 The pages of Accountability · 2 Collection Type and Cemetery.

Almost every page works the same way. Section 2.1 explains the common parts once. The pages that differ say so in their own sections.

How messages are shown in this manual. The questions and messages that TIS shows in its windows are written in a colored box. The color tells you what kind of message it is:

  • Are you sure to delete this group? Gray: a question or a notice. A question waits for your answer.
  • Fund code deleted successfully Green: success. The action worked: a record was created, updated or deleted.
  • Required Red: an error. Something is wrong and the action did not happen until you correct it.
  • An active record already exists. New record will be saved as inactive. Yellow: a warning. The action can continue, but be careful.

2.1.1 The list page

  1. Search: type part of a code or a description to find a record. The list shows only the records that match.
  2. Add button (blue, at the top right): opens the window for a new record. Its label names the record, for example ADD CODE or ADD GROUP.
  3. Table headings: the columns of the list.
  4. Action icons: the pencil (EDIT) opens the record for changes. The trash can (DELETE) removes the record after you confirm. Point to an icon to see its name.

A list that has nothing to show says No record found.

2.1.2 Adding a record

  1. Click the blue Add button.
  2. Fill in the boxes of the window. A drop-down box opens a list: click it and click your choice. A dash (-) at the top of a list means that nothing is chosen.
  3. Click Create. The message ... created successfully appears and the new record is in the list.

When you leave a required box empty, its border turns red and the word Required appears under it. You cannot save the record until every required box is filled in. Press the Esc key or click the gray area outside the window to close it without saving.

2.1.3 Editing a record

  1. Click the pencil of the record. The window Editing and the name of the record opens with the present values.
  2. Change the boxes that need a change.
  3. Click Update. The message ... updated successfully appears.

2.1.4 Deleting a record

Click the trash can of the record. A small window asks a question such as Are you sure to delete this group? Click No to keep the record. Click Yes to remove it. After Yes, the message ... deleted successfully appears.

Figure 2.3. The question before a record is deleted (Fund Group is shown). 1 The question · 2 No keeps the record · 3 Yes removes it.
Be careful with Yes. Other pages and receipts use these records. Delete a record only when you are sure that nothing depends on it.

The question always names the kind of record, for example Are you sure to delete this code?, this group?, this payee? or this cost center?. After Yes, a message tells you that the record was deleted, such as Fund code deleted successfully. In the same way, a new record shows a ... created successfully message and a changed record shows an ... updated successfully message.

A few pages differ. On the Accountant, Treasurer and Mayor pages the question reads Are you sure you want to delete (the name)? and the buttons are Cancel and Yes. On the Accountable Forms page the Delete icon appears only for a record from which no receipt has been issued yet. The Check Booklets page has no Edit or Delete icon.

In the window CREATE ACCOUNTABLE FORM:

  • Liquidating Officer, Collector, Cost Center, Form Type and Fund are required lists.

2.6.10 How OR Template and Collection Type work together

The relationship in one line. A Collection Type is the kind of payment that a cashier chooses (for example 006 Amusement). The OR Template is the list of accounts that belong to that collection type. One collection type has many OR template lines, and each OR template line belongs to one collection type.

Each line of the OR Template page links one account of the chart of accounts (Section 2.5.1) and one fund (Section 2.2.2) to one collection type. The usual amount of the account is kept on the line. The lines of a collection type together make up what is printed on the official receipt for that kind of payment.

A sample: the collection type Amusement. First, the Collection Type page lists 006 Amusement. It is only a code and a name.

Figure 2.79. Step 1. The collection type 006 Amusement on the Collection Type page. 1 The Search box with the word typed · 2 The code and the name of the collection type.

Second, the OR Template page lists the lines that belong to Amusement. Typing Amusement in the Search box of the OR Template page finds them, because the search also matches the collection type. Amusement has eight lines: Business Tax-Amusement, Health and Sanitary Permit, Occupation Fees, Other Fees, Permit Fees-Business (Mayor's Permit), Registration Plates, Tags and Stickers Fees, Penalty and Garbage Fees. Seven lines have an amount of 0.00 and Garbage Fees has 30.00. All eight use the fund 100(01).

Figure 2.80. Step 2. The eight OR template lines of the collection type Amusement. 1 The Search box · 2 The Collection Type column (every line says Amusement) · 3 The account code and the description of each line · 4 The amount and the fund of each line.

Third, click the pencil of any line. The window shows the link: the Account Code, the Collection Type that the line belongs to, and the Fund. To move a line to another collection type, change the Collection Type box and click Update.

Figure 2.81. Step 3. The window of one OR template line. 1 The account of the line · 2 The Collection Type of the line (Amusement) · 3 The fund of the line.

Where the cashier sees it. On the Issuance of Official Receipt page, the cashier chooses a collection type. TIS then loads the OR template lines of that collection type (the accounts, the amounts and the funds) and the cashier adds them to the receipt. This part is described from the system's code and is shown in the Transaction section of this manual.

To make a new kind of payment available:

  1. Add the collection type on the Collection Type page (Section 2.7).
  2. On the OR Template page, add one line for each account of that payment. In every line choose the same Collection Type, then the Account Code, the Account Group and the Fund.
  3. Check the result by typing the name of the collection type in the Search box of the OR Template page.
Caution. A collection type with no OR template line gives the cashier nothing to load. Deleting a collection type or a line changes the receipts of that kind of payment from then on.

2.6.12 Treasurer

Treasurer lists the municipal treasurers. The columns are #, Full Name, Position, Status and Action. The status Active marks the treasurer that the system uses at present. Only one record can be active.

Figure 2.84. The Treasurer page. 1 Search box · 2 Add button · 3 Table headings · 4 Action icons (Edit, Delete)

Figure 2.85. The window to add a record in Treasurer. 1 Full Name · 2 Position · 3 Cancel · 4 Add Treasurer

2.7 Collection Type

Collection Type lists the types of collection that the cashier chooses from. The columns are Code and Description. The list is long (171 types), so use the Search box. In the window to add a record, type the Code and the Description. Both are required.

A collection type is only a code and a name. The accounts that belong to it are set on the OR Template page. See Section 2.6.10.
