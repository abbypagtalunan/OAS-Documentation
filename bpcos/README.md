# BPCOS user manual

User manual for the Building Permit and Certificate of Occupancy System (BPCOS) of the Municipality of Oas, Albay.
Live site: https://bpcos.oas.lguapp.com

Built the same way as the eBPLS manual in `../manual`:
- One HTML file per section, styled by `manual.css`, rendered to PDF with headless Chrome.
- Images in `images/` (PNG, personal data covered, red boxes on the buttons to click).
- `VERIFY.md`: things to confirm on the live site.
- `SCREENSHOTS-NEEDED.md`: the screenshot checklist.

Planned structure (to confirm once the roles and the flow are known):
1. Introduction
2. Getting Started with BPCOS (sign in, create an account, forgot password)
3. Applicant guide
4 and up. One section for each staff role

The source code is the repo https://github.com/iConcept-IT-Solutions/ebpls-engineering-oas (cloned next to this folder as `../ebpls-engineering-oas`, ignored by git). See `BPCOS-System-Flow-Overview.md`.
